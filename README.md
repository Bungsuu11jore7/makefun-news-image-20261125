# The World Today — 25 November 2026

One day of world news — Wednesday 25 November 2026 — in a single 1024×1024
image: 38 verified stories across 7 regions and 14 fields, 13 original drawn
scenes, a UTC timeline, an IN NUMBERS strip, a 25-more list, a pin map and a
date check of what was left out. Every story happened or was first reported
on Wednesday 25 November 2026 (UTC); sources are named on each item.

## Run it

```sh
python3 main.py
```

This writes `entry.png` to `/output` (or `$MAKEFUN_OUTPUT_DIR` if set).
The build is deterministic: two runs produce byte-identical output.
